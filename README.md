
# Christina Saroglaki | Developer Portfolio

## A little code, a lot of curiosity, and a portfolio to bring it all together.

Welcome to my personal corner of the internet! 👋

This portfolio is more than a collection of projects. It's a space where I showcase what I've built, the technologies I've explored, and how I've grown as a software engineer.

Designed and developed from scratch using React, TypeScript, and Vite, the website combines clean architecture, responsive design, and thoughtfully crafted animations to create an interactive experience that reflects both my technical skills and personality.


## ✨ Highlights

- Interactive Landing Page — An animated introduction, featured projects, and quick access to my work and contact information.

- Project Showcase — A paginated gallery featuring project descriptions, technology stacks, screenshots, key features, and links to repositories and live demos.

- About Me — A closer look at my background, technical skills, professional experience, and downloadable CV.

- Responsive Design — A seamless experience across desktop, tablet, and mobile devices, including an animated mobile navigation menu.

- Thoughtful Animations — Smooth transitions, interactive elements, and a custom cursor that add personality without sacrificing usability.

## 🛠️ Tech Stack
The portfolio is built with a modern frontend stack, chosen for maintainability, performance, and flexibility.

- **React 19** and **TypeScript** for the component-based interface.
- **Vite 7** for development and production builds.
- **React Router 7** for client-side routing.
- **Tailwind CSS 4** and component CSS for styling.
- **Motion** and **GSAP** for animations.
- **ESLint** for code quality checks.

## 🚀 Getting Started

Want to explore the code or run the portfolio locally?

Prerequisites

Make sure you have the following installed:

Node.js — Version 20.19+ (20.x), or 22.12+

npm — Included with Node.js

Installation

1. Clone the repository
```sh
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```
2. Install dependencies
```sh
npm ci
```
3. Start the development server
```sh
npm run dev
```
2. Install dependencies

npm ci

3. Start the development server

npm run dev

4. Open the application

Visit the local URL displayed in your terminal (typically http://localhost:5173).

No API keys, environment variables, or backend configuration are required. The current version uses local JSON files for its content.
